# Marketing Localization Glossary (Session 13)

**2026-08-13 · Status: DRAFT — professional review required for all non-English terms.**

Terminology decisions for the Hindi/Telugu/Urdu marketing candidates. Brand names stay in Latin; common English loanwords are used where they read more naturally to patients than an obscure formal coinage (§8). Reviewers: confirm or correct each non-English term; flag anything that would confuse an older patient, a caregiver, or a low-literacy reader.

**Numerals (§24):** the copy uses no dose-pattern notation (e.g. `1-0-1`) — where such notation appears in the *product*, it stays Latin digits and is not localized. Demo values (`Glucomet 500`, `Metformin 500 mg`, `Dr. Rao`) and language autonyms (`English · हिंदी · తెలుగు · اردو`) are intentionally identical across all locales.
